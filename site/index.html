Benchmark · coding agents · optimization

Can coding agents design decomposition algorithms?

DecompGym asks an agent to write a standalone solver that uses Benders decomposition or column generation. Each attempt must run, pass a feasibility check and a method audit, and come within 1% of the reference objective.

About these results
Snapshot
Configurations
12, all at medium effort: five GPT models through Codex 0.162.1, six Claude models through Claude Code 2.1.296, Gemini 3.8 Flash through Antigravity 1.3.1.
Instances
81 fixed instances: 9 families × 3 sizes × 3 seeds. Benders decomposition: UFL, FCTP, KM, LRP, TSSO (45). Column generation: BP, CSP, GAP, SHIFT (36).
Protocol
Every agent call runs in a fresh Docker container with an empty workspace. Each solver runs natively in a sandbox for at most 60 s on one configured thread (Gurobi 11.0.3, Apple silicon). Up to 10 attempts per policy; the first attempt is shared.
Method judge
GPT-6 Astra at high effort reads the solver source and decides whether the requested decomposition is genuinely used.
Agent time
Seconds spent in generation and reflection calls; judge and solver time are reported separately. Pauses from the resource monitor are excluded.
Tokens
Context + output tokens summed over agent calls (Codex: input + output; Claude: input + cache creation + cache read + output). Not a price.

Efficiency

How much agent time (or how many tokens) each configuration needs per instance. A point at (t, y) means y% of the selected instances reached a quality solution within an agent budget of t per instance.

About DecompGym

81 fixed instances from nine problem families. Every agent call runs in a fresh Docker container; every solver runs in a sandbox for at most 60 seconds on one thread.

01Task

Instance data, the output contract and a method contract: use the named decomposition, no monolithic model, claim optimality only with a proof.

02Agent writes solver.py

A Codex, Claude Code or Antigravity agent edits a single file in an empty workspace.

03E · Executable

The solver finishes within 60 s and writes a parseable output.json.

04V · Verified

An independent checker confirms feasibility; a method judge confirms the decomposition is really used.

05Q · Quality

Verified and within 1% of the reference objective. Otherwise, retry: plain or with reflection.
