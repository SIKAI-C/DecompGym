# LRP scaling pilot: review guide

This is an exploratory location-routing pilot, developed locally with Codex. It extends the original route-enumerated LRP family with generated instances, HiGHS baselines, LP-first and integer-cut Benders variants, an exact-cover recourse solver, and tests. It is separate from `explore/harder-families` and does not replace its new families.

Start with [the implementation README](../src/pilots/lrp/README.md) for setup, commands, algorithms, and numerical tolerances. [The lower-bound report](lrp-lower-bounds.md) explains the strongest result. The [saved comparison](../pilot-artifacts/lrp/bounds/report.md) and [summary table](../pilot-artifacts/lrp/bounds/summary.csv) cover the nine matched pilot inputs. The [evidence archive](../pilot-artifacts/lrp/lrp-bounds-evidence.zip) contains all nine original data files, full run records, frozen source snapshots, and 256-pattern certificate records. Extract it to inspect the JSON files or rerun the certificate checker against its `bounds/` directory. Earlier timing summaries are in `pilot-artifacts/lrp/benders-improvement/`.

On three 40-customer cases, the exact-cover Benders variant reports matching numerical bounds within 1e-7 in 1.2–3.1 seconds; a same-budget HiGHS full MIP returns feasible solutions without closing its gap. The separate depot-pattern enumeration audit does not use the Benders master, but **shares the same exact-cover search**; exhaustive tiny-instance tests provide an independent check. Please review the code, numerical safeguards, and certificates before relying on these claims.

The larger cases use sampled route pools, and their tight fleet/route-length structure helps the specialized search. This is optimality over the supplied routes, not general unrestricted LRP. The comparison uses HiGHS for LP/MIP and custom Python for exact-cover recourse; it is not a Gurobi reproduction or an agent evaluation, nor a general speedup claim. Earlier experiment manifests record a dirty local checkout and original local Git identities; the included source snapshots and hashes identify the actual code used. Machine timings are exploratory.

The artifacts retain the original run's data hashes and numerical output. Reproduce with a fresh output directory using `configs/lrp_pilot_bounds.json`, then run the enumeration audit. This sharing branch was squashed onto the original main snapshot to omit private planning notes; the original local work remains intact separately.
